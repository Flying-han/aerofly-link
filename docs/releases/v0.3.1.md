# Aerofly Link 0.3.1

## Changes

- Set the new-install default to Aviation Simulation Community FSD at `flight.skeet.top:6809`; remove Sweatbox and stale VATSIM hosts from default server history.
- Show VATSIM's `AUTOMATIC` address as reference only and block direct `*.vatsim.net` connections because Aerofly Link is not listed as approved software.
- Replace the fixed Win32 control grid with a resizable Nuklear/GDI interface. Add a guided connection page, connected flight workspace, explicit server actions, and GUI controls for language, theme, authentication, proxy, and simulator test settings.
- Add Simplified Chinese, Hong Kong Traditional Chinese, and American English, plus dark and light themes.
- Use `auth_mode: "fsd-jwt"|"legacy"` in new settings; continue reading old `type`/`eco` keys. Passwords remain memory-only.
- Harden settings JSON serialization with escaping and atomic replacement. Reject malformed JWT URLs and disable automatic redirects for credential-bearing HTTPS requests.

## Platform

Windows 10 and later. Linux and macOS are not claimed by v0.3.1. Live Aerofly telemetry still requires the external AeroflyBridge DLL. Windows 10 Home/Pro reached end of support on 2025-10-14; use a supported Windows release or a currently enrolled ESU device.
