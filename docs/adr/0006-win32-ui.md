# ADR 0006: C 客户端 UI 选型——Win32 原生

- 状态: 已接受（2026-09-18）
- 关联: ADR 0001（C 重写）、docs/C_REWRITE_PLAN.md §6 P3

## 背景

C 重写到达 UI 阶段（P3）。候选：Win32 原生 / Qt(C++) / web 前端壳（WebView2）。

## 决策

**Win32 原生（纯 C + 公共控件）**，理由：

1. 零依赖、单文件分发目标（G5）——Qt 引入数十 MB DLL，WebView2 依赖系统运行时；
2. 与单线程 select 事件循环天然契合（WM_TIMER 驱动 app_poll(0)，UI 永不阻塞）；
3. 本客户端 UI 面积小（两页面 + 状态栏），不需要布局引擎；
4. 保持全栈 C，贡献者无需掌握第二种语言与构建体系。

## 取舍

- 视觉打磨（暗色主题、DPI manifest、Per-Monitor V2）列入 P3 backlog；
  首版为标准浅色控件、系统 DPI 虚拟化（截图核验可读性可接受）。
- Enter 键行为通过局部子类化两个输入框实现（消息发送/代码确认），
  不引入对话框管理器全权接管。
