# ADR 0006: C 客户端 UI 选型——Win32 原生

- 状态: 已接受（2026-09-18）
- 关联: ADR 0001（C 重写）、docs/C_REWRITE_PLAN.md §6 P3

## 背景

C 重写到达 UI 阶段（P3）。候选：Win32 原生 / Qt(C++) / web 前端壳（WebView2）。

## 决策

**Win32 原生（纯 C + 公共控件）**，理由：

1. 零依赖、单文件分发目标（G5）——Qt 引入数十 MB DLL，WebView2 依赖系统运行时；
2. 与单线程 select 事件循环天然契合（WM_TIMER 驱动 app_poll(0)，UI 永不阻塞）；
3. 本客户端 UI 面积小（两页面 + 状态栏），不需要布局引擎；
4. 保持全栈 C，贡献者无需掌握第二种语言与构建体系。

## 视觉形式：Apple HIG 风格深色主题（2026-09-19 增补）

三步落地（原"形式自由"留白的正式定义）：

**第一步：现代控件（纯技术）**
- 外挂 `aeroflylink.exe.manifest` 声明 comctl32 v6 + PerMonitorV2 DPI；
- `DwmSetWindowAttribute` 深色标题栏（attr 20）+ 圆角窗口（attr 33，DWMWCP_ROUND）。

**第二步：视觉语言**
- 配色：背景 `#1C1C1E`、卡片/输入 `#2C2C2E`、强调 Apple 蓝 `#0A84FF`、
  主文字 `#F5F5F7`、次要 `#98989D`、语义色 绿 `#30D158` 橙 `#FF9F0A` 红 `#FF453A`；
- 按钮：主操作（连接服务器）owner-draw 圆角胶囊实心白字；次操作
  （快捷码/提交/发送/断开）着色文字 + 卡片底，hover 微亮（BS_OWNERDRAW +
  TrackMouseEvent 子类化，每按钮独立保存原 proc——共享单槽会破坏绘制链）；
- 去 GROUPBOX：圆角卡片（父窗口 WM_PAINT 自绘）+ 大写小字分节标题
  （TRANSPONDER / FLIGHT PLAN / ATC MESSAGES）；
- 字体：Segoe UI 层级（标题 24 半粗 / 正文 14 / 小字 12 / 代码 24 等宽粗体），
  全部按窗口 DPI 经 SC() 缩放；
- 布局：标签在输入框上方，8pt 网格。

**第三步：细节质感**
- 输入框无立体边：深底自绘配色（WM_CTLCOLORREDIT）+ 聚焦 1px 蓝描边
  （EN_SETFOCUS/KILLFOCUS 驱动父窗口重绘）；
- 应答机代码等宽大字号绿字（保留 Python 版基因）；
- IDENT 激活期橙色实心 + 呼吸（正弦插值两档橙），空闲期为橙字浅底；
- 模拟DLL 开关为 Apple 式轨道旋钮自绘。

**已知取舍（backlog）**
- 组合框（CBS_DROPDOWN）内嵌编辑区在 v6 主题下仍为浅色——完整暗色需
  自绘下拉（v2）；ECO/TYPE 文本截断显示首字符的现象与主题渲染相关，
  功能（选择/读取）不受影响；
- IDENT 呼吸经 WM_TIMER 100ms 步进，非连续动画。

## 取舍（其余）

- Enter 键行为通过局部子类化两个输入框实现（消息发送/代码确认），
  不引入对话框管理器全权接管。
